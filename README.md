# Happ Rotation Script

Скрипт для **автоматической смены серверов внутри уже добавленной подписки Happ Desktop**.

Для твоего сценария:

```text
LagomVPN
├─ Германия
├─ Финляндия
├─ Швеция
├─ Великобритания
├─ Италия
├─ Япония
├─ США
├─ Турция
└─ YouTube (Глобальный)
```

скрипт не создаёт новый VPN-профиль и не импортирует Xray JSON. Он оставляет существующую подписку `LagomVPN` как есть и выбирает следующую строку сервера прямо в уже открытом Happ.

## Почему используются координаты

Happ 4.3.x отрисовывает список серверов как кастомный UI. На проверенной сборке главное окно находится через Win32, но список серверов **не экспортируется в Windows UI Automation**: `ui-tree.txt` получается пустым.

Поэтому текущая реализация:

1. находит реальное окно `Happ.exe`;
2. получает его client rect;
3. вычисляет положение нужной строки относительно размеров окна;
4. выводит Happ на передний план;
5. кликает по центру нужной строки;
6. запоминает последний выбранный сервер.

Размер и положение окна на экране могут меняться: координаты хранятся как относительные коэффициенты, а не как абсолютные пиксели.

## Требования

- Windows 10/11;
- Happ Desktop 4.3.x;
- Python 3.10+.

**Внешние Python-библиотеки больше не нужны.** `pywinauto` из первой версии удалён.

## Установка / обновление

```powershell
git clone https://github.com/m-amirov/happ-rotation-script.git
cd happ-rotation-script
```

Если репозиторий уже скачан:

```powershell
git pull
```

Создай локальный конфиг:

```powershell
Copy-Item .\config.example.json .\config.json
```

## Текущий config.example.json

Пример уже соответствует списку на скриншоте:

```json
{
  "subscription": "LagomVPN",
  "servers": [
    "Германия",
    "Финляндия",
    "Швеция",
    "Великобритания",
    "Италия",
    "Япония",
    "США",
    "Турция"
  ],
  "mode": "round-robin",
  "interval_seconds": 600,
  "settle_seconds": 4,
  "happ_window_regex": "^Happ(?:\\s|$).*",
  "process_names": [
    "happ.exe"
  ],
  "click_x_ratio": 0.365,
  "first_server_y_ratio": 0.322,
  "row_step_ratio": 0.0713
}
```

`YouTube (Глобальный)` намеренно не включён в ротацию.

## Сначала обновиться

После перехода с UI Automation на координатный режим обязательно:

```powershell
git pull
```

Проверить, что запускается новая версия:

```powershell
py .\happ_rotation.py -h
```

В справке должны быть параметры:

```text
--calibrate
--preview-clicks
--list-windows
```

## Шаг 1. Найти окно Happ

Открой Happ и страницу **Серверы**. Подписка `LagomVPN` должна быть раскрыта.

Проверь:

```powershell
py .\happ_rotation.py --list-windows
```

В списке должна быть строка с `Happ.exe` или заголовком Happ.

## Шаг 2. Калибровка

Это наиболее надёжный вариант и занимает меньше минуты:

```powershell
py .\happ_rotation.py --calibrate
```

Скрипт ничего не кликает сам во время калибровки.

Он попросит:

1. поставить курсор **в центр строки «Германия»** и нажать Enter в PowerShell;
2. поставить курсор **в центр строки «Финляндия»** и снова нажать Enter.

После этого в `config.json` автоматически сохранятся реальные коэффициенты:

- `click_x_ratio`;
- `first_server_y_ratio`;
- `row_step_ratio`.

Калибровка учитывает текущий размер окна Happ и DPI Windows.

## Шаг 3. Посмотреть расчётные точки без кликов

```powershell
py .\happ_rotation.py --preview-clicks
```

Будет что-то вроде:

```text
00  Германия: (1184,217)
01  Финляндия: (1184,265)
02  Швеция: (1184,313)
...
06  США: (1184,505)
07  Турция: (1184,553)
```

Это только расчёт — мышь не двигается.

## Шаг 4. Dry run

```powershell
py .\happ_rotation.py --server "Германия" --dry-run
```

Скрипт покажет рассчитанную строку и координату, но не нажмёт её.

## Шаг 5. Реальная проверка

Если сейчас выбран `США`, удобно проверить переход на Германию:

```powershell
py .\happ_rotation.py --server "Германия"
```

Happ должен выбрать строку `Германия`. При активном VPN Happ сам должен выполнить переключение соединения.

## Автоматическая ротация

Один следующий сервер:

```powershell
py .\happ_rotation.py --once
```

Постоянный режим:

```powershell
py .\happ_rotation.py
```

По умолчанию:

```text
Германия
→ Финляндия
→ Швеция
→ Великобритания
→ Италия
→ Япония
→ США
→ Турция
→ Германия
```

Интервал:

```json
"interval_seconds": 600
```

то есть 10 минут.

Для случайной смены:

```json
"mode": "random"
```

## Если список содержит дополнительные строки между серверами

По умолчанию номер строки берётся из порядка массива `servers`.

Если, например, между Японией и США появится дополнительная строка, можно явно задать индексы:

```json
"server_rows": {
  "Германия": 0,
  "Финляндия": 1,
  "Швеция": 2,
  "Великобритания": 3,
  "Италия": 4,
  "Япония": 5,
  "США": 6,
  "Турция": 7
}
```

Индексация начинается с нуля.

## Важные условия

- Подписка должна быть **раскрыта**, чтобы строки серверов находились на своих местах.
- Во время самого переключения окно Happ должно существовать в пользовательской Windows-сессии.
- Скрипт выводит окно Happ на передний план перед кликом.
- Курсор после клика возвращается в прежнее положение.
- При сильном изменении интерфейса/масштаба Happ просто повтори `--calibrate`.
- Если VDI-сессия полностью отключена и Windows не предоставляет интерактивный desktop, синтетический click может не пройти.

## Безопасность

Скрипт не:

- читает VPN-ключи;
- меняет URL подписки;
- редактирует внутреннюю базу Happ;
- создаёт новый Xray/VLESS-профиль;
- отправляет данные наружу.

Он работает только с окном Happ через стандартный Win32 API.
